# Python Activity-Based Learning

This repository contains **10 selected case-study solutions** for the Python Programming
Activity-Based Learning assignment. Each case study is implemented using only the prescribed
syllabus:

> computational thinking, algorithms, flowcharts, pseudocode, variables, data types,
> operators, conditional statements, loops, strings, pattern generation, lists, nested lists,
> tuples, tuple operations, and unpacking.

No object-oriented programming or dictionaries are used — only basic Python foundations.

## Deliverables (per case study)

Each `Case_Study_XX_*` folder contains:

- `README.md` — problem statement, objectives, assumptions, algorithm, flowchart, pseudocode, test cases, conclusion
- `source.py` — the Python program
- `output.txt` — the actual program output
- `output_screenshot.png` — a screenshot of the program run

The single combined report **`Python_Activity_Report.pdf`** contains all 10 case studies, one
by one, embedding every section and file (problem statement, objectives, assumptions, algorithm,
flowchart, pseudocode, source code, test cases, output screenshots, and conclusion).

## How to Run

Each program is standalone. From a case-study folder:

```bash
python3 source.py
```

Tested with Python 3.13.
